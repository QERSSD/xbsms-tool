# xbsms-tool 短信验证工具

基于 Node.js + H5 的短信验证码接收工具，代理 [xbsms.work](https://xbsms.work) 国内通道 API，提供简洁的网页操作界面。

## 简介

在网页上完成 **获取手机号 → 接收短信 → 释放/拉黑号码** 的完整流程，适用于需要临时手机号接收验证码的场景。

**架构：** H5 前端 → Node.js 后端（Express 代理）→ xbsms.work API

后端作为代理层转发请求，解决浏览器跨域问题；API 密钥、关键词、卡类型全部在后端写死，前端只做展示与操作，不暴露任何配置。

## 功能特性

- **获取手机号** — 选择省份（支持 34 个省份筛选），一键分配实卡号码
- **复制号码** — 一键复制到剪贴板，用于登录目标 APP
- **已发短信（10 秒倒计时）** — 防止过早查询，倒计时结束后开始轮询
- **自动轮询短信** — 每 2 秒查询一次，最多 20 次，收到短信自动停止并展示内容
- **短信内容常驻展示** — 获取成功后内容保留在页面上，方便对照操作
- **释放 / 拉黑号码** — 操作完成后自动重置，可重新获取
- **一人一号** — 每个用户同时只能占用一个号码，获取失败可重试，释放后归还名额；刷新页面自动恢复当前号码
- **请求日志** — 默认隐藏，可展开查看每次请求与响应明细
- **响应解包** — 自动识别上游接口的 JSON 引号编码，失败一律返回错误信息，不会误报成功

## 使用说明

### 本地运行

```bash
# 1. 安装依赖（需要 Node.js 18+）
npm install

# 2. 启动服务
npm start
```

浏览器打开 **http://localhost:3000** 即可使用。

### 操作流程

1. **选择省份** — 默认「全部」随机分配，也可指定具体省份
2. **点击「获取手机号」** — 系统分配一个实卡号码
3. **复制号码** — 粘贴到目标 APP（如「多点」）触发发送验证码
4. **等待 10 秒** — 「已发短信」按钮 10 秒后解锁
5. **点击「已发短信」** — 开始轮询，收到短信后内容直接显示在页面上
6. **点击「释放号码」** — 用完释放（也可「拉黑号码」标记问题号），之后可获取新号码

### 固定配置（后端写死，无需设置）

| 配置项 | 值 |
|--------|-----|
| 关键词 | 多点 |
| 卡类型 | 实卡 |
| API 密钥 | 在 `server.js` 中配置 |
| 轮询间隔 | 2 秒 × 最多 20 次 |
| 已发短信等待 | 10 秒 |

## 部署（Railway）

1. 将本仓库导入 [Railway](https://railway.app)（New Project → Deploy from GitHub）
2. Railway 自动识别 `package.json`，执行 `npm install` → `npm start`
3. 在 Settings → Networking 点击 **Generate Domain** 生成公网地址

## API 接口

后端提供以下接口供前端调用（也可直接 curl 测试）：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/getPhone` | POST | 获取手机号（body: `{province}`） |
| `/api/getMsg` | POST | 查询短信（body: `{phone}`） |
| `/api/release` | POST | 释放号码（body: `{phone}`） |
| `/api/block` | POST | 拉黑号码（body: `{phone}`） |
| `/api/myPhone` | GET | 查询当前占用的号码（刷新恢复用） |
| `/api/config` | GET | 查询关键词、卡类型配置 |

响应格式统一为：

```json
{ "ok": true, "data": "..." }
{ "ok": false, "error": "ERROR:xxx", "retryable": false }
```

- `retryable: true` 表示轮询期间的正常状态（如 `ERROR:未收到短信`），前端继续等待
- 其他错误立即终止并提示

├── index.html      # H5 前端（单文件，零构建）

## 注意事项

- ⚠️ **仓库请保持 Private** — `server.js` 中包含 API 密钥
- 获取号码后请尽快使用，长时间未收到短信建议释放后重新获取
- 「一人一号」以内存记录（按 IP 识别），服务重启后清空，不影响正常使用
